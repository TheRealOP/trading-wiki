# Meta-Labeling and Financial ML
## Key Insight
[[Meta-labeling]] is a technique from [[Advances in Financial Machine Learning]] that improves [[trading strategy|trading strategies]] by separating the prediction of trade direction (side) from the decision of whether to act on the signal (size). A primary model with high [[recall]] identifies many potential trading opportunities. A secondary ML model then filters these for high [[precision]], effectively deciding *if* and *how much* to bet, reducing false positives and improving the overall [[Sharpen_Ratio|Sharpe Ratio]].

## The Math
The process involves a two-stage model setup:
1.  **Primary Model ($M_1$)**: Generates the initial signal, predicting the side of a trade. This model can be a simple heuristic like a [[moving average]] crossover or another ML model.
    $$ \hat{y}_{side} = M_1(X) \in \{-1, 1\} $$
2.  **Secondary Model ($M_2$)**: A binary classifier that predicts the probability of the primary signal being profitable. It's trained on *meta-labels*.
    $$ y_{meta} = \begin{cases} 1 & \text{if primary signal was profitable} \\ 0 & \text{otherwise} \end{cases} $$
    The secondary model then gives the confidence for sizing the position.
    $$ p = P(y_{meta}=1 | X) $$
    The final position size can be a function of this probability, e.g., $size = f(p)$.

## Strategy Logic
1.  Develop a primary model ($M_1$) that generates trading signals (e.g., long/short). This model should be optimized for high [[recall]] (capturing many potential opportunities), not precision.
2.  Use the [[Triple-Barrier Method]] to label the outcome of each primary signal. A trade is labeled based on whether it hits a profit-take, a stop-loss, or a time limit barrier first.
3.  Create meta-labels ($y_{meta}$). If the trade hits the profit-take barrier, $y_{meta}=1$; otherwise, $y_{meta}=0$.
4.  Train a secondary classification model ($M_2$) using the original features ($X$) to predict the meta-labels. This model learns to identify which of the primary signals are likely to be profitable.
5.  In live trading, only execute trades when $M_2$ gives a high probability score, using the probability to inform [[quantitative_risk_management_position_sizing|position sizing]].

## Parameters
- Primary model structure (e.g., [[algorithmic_trading_with_moving_averages|moving average periods]])
- [[Triple-Barrier Method]] levels: profit-take (e.g., +2%), stop-loss (e.g., -1%)
- Secondary model type (e.g., RandomForest, LightGBM)
- Confidence threshold from $M_2$ to trigger a trade.

## Risks
- [[Backtest Overfitting]]: The two-stage process is complex and can be easily overfit to historical data.
- [[Data Snooping]]: Features used in the model must be point-in-time to avoid look-ahead bias.
- Feature Importance Instability: The features that are important for predicting profitability can change over time.
